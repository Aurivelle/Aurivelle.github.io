This is a final project of the class Advanced Data Structure aiming on probalistic data structure implementation and performance measurement in fuzzy counting.

### Key Features

Implemented two classic algorithms to estimate the cardinality of large-scale data streams.
Features custom-built hash functions and low-level bit manipulation in C++.
Conducted detailed experiments to compare estimation accuracy and error rates under various parameters.
